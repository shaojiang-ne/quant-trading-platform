# 量化交易平台 (Quant Trading Platform)

一个现代化的量化交易平台前端项目，支持多账户管理、策略回测和实盘交易。

## 功能特性

### 1. 多账户管理
- 支持实盘账户和虚拟账户
- 账户资产总览
- 持仓管理
- 委托查询

### 2. 策略中心
- 内置多种经典策略模板
  - 双均线策略
  - MACD策略
  - 布林带突破
  - 网格交易策略
  - RSI超买超卖
- 策略参数配置
- 策略科普教育

### 3. 回测系统
- 历史数据回测
- 实时回测进度
- 详细的回测指标
  - 收益率、最大回撤
  - 夏普比率、索提诺比率
  - 胜率、盈亏比
- 权益曲线可视化

### 4. 实盘交易
- 买入/卖出交易
- 市价/限价委托
- 持仓管理
- 当日委托查询

## 技术栈

- **框架**: React 18 + TypeScript
- **构建工具**: Vite
- **路由**: React Router
- **状态管理**: Zustand
- **样式**: Tailwind CSS
- **图表**: Recharts
- **图标**: Lucide React

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发环境

```bash
npm run dev
```

访问 http://localhost:5173

### 生产构建

```bash
npm run build
```

## 项目结构

```
src/
├── components/        # 公共组件
├── pages/            # 页面组件
│   ├── Dashboard.tsx    # 仪表盘
│   ├── Accounts.tsx     # 账户管理
│   ├── Strategies.tsx   # 策略中心
│   ├── Backtest.tsx     # 回测系统
│   ├── Trading.tsx      # 实盘交易
│   └── Settings.tsx     # 系统设置
├── stores/           # 状态管理
├── mocks/            # Mock数据
├── types/            # TypeScript类型
└── utils/            # 工具函数
```

## Mock 数据

项目使用Mock数据模拟后端API，包含：
- 4个账户（2个实盘、2个虚拟）
- 5只股票行情
- 5种交易策略
- 回测结果示例

## 界面预览

### 仪表盘
展示总资产、累计盈亏、账户数量等关键指标

### 账户管理
管理实盘和虚拟账户，查看持仓和委托

### 策略中心
浏览策略模板、学习策略原理、配置策略参数

### 回测系统
配置回测参数、查看回测结果和权益曲线

### 实盘交易
执行买卖交易、管理持仓和委托
