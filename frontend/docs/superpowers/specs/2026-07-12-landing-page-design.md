# 落地页设计文档

## 概述

为量化交易平台新增一个公开访问的落地页（Landing Page），用于产品介绍、宣传和推广。核心定位：使用AI进行选股、盯盘、策略生成和回测，解决有策略但不会写代码的人做量化的问题。

## 目标受众

有经验的散户投资者——有一定投资经验，了解基本面/技术面，但不会编程，想用AI工具实现量化策略。

## 视觉风格

科技金融风：深色背景、数据可视化元素、K线图/指标动画，类似专业交易终端的感觉。

## 技术方案

**方案 A：独立路由页面**

- 在现有 React Router 中新增 `/` 路由指向落地页组件
- 落地页不受 `ProtectedRoute` 保护，公开访问
- 原有应用路由移至 `/app` 前缀下
- 使用同一套技术栈（React + Tailwind + Lucide Icons + Recharts）
- CTA 按钮通过 `navigate('/login')` 跳转到现有登录页

## 路由改造

### 改造前

```
/           → ProtectedRoute → 重定向到 /ai-assistant
/login      → 登录页（已登录则重定向到 /）
/*          → ProtectedRoute → 重定向到 /trading-data
```

### 改造后

```
/           → Landing（公开，无需认证）
/login      → 登录页（不变）
/app        → ProtectedRoute → 重定向到 /app/ai-assistant
/app/ai-assistant     → AI分析
/app/ai-agent         → AI智能体
/app/strategy-workspace → 策略与回测
/app/simulation       → 模拟交易
/app/trading          → 实盘交易
/app/factor-board     → 因子看板
/app/trading-data     → 数据源
/app/settings         → 系统设置
/app/*                → 重定向到 /app/ai-assistant
```

### 已登录用户行为

- 访问 `/` 仍然显示落地页（不自动重定向）
- 落地页顶部导航栏显示"进入工作台"按钮，点击跳转 `/app`

## 页面结构

落地页为长滚动页面，包含以下板块：

### 1. 固定导航栏

- 左侧：Logo（TrendingUp 图标）+ "量化交易平台" 品牌名
- 右侧：锚点导航（功能、效果、FAQ）+ 登录按钮 + "免费注册" CTA 按钮
- 滚动时背景从透明变为半透明深色毛玻璃效果

### 2. Hero 区域

- 深色渐变背景（深蓝→深灰），带微妙网格/数据流背景
- 主标题：**让AI成为你的量化交易引擎**
- 副标题：无需编程，用自然语言描述策略，AI帮你选股、盯盘、回测、执行
- 两个 CTA 按钮：
  - "立即体验"（主按钮，primary 色，跳转 `/login`）
  - "了解更多"（次按钮，锚点滚动到功能区域）
- 背景装饰：抽象K线图/数据曲线动画元素

### 3. 核心功能展示

- 区域标题：四大核心能力
- 4 个功能卡片，2×2 网格布局（移动端 1 列）
- 每个卡片：图标 + 功能名称 + 简短描述 + 功能点列表

| 功能 | 图标 | 描述 | 功能点 |
|------|------|------|--------|
| AI选股 | Sparkles | 自然语言描述选股条件，AI自动筛选符合要求的标的 | 自然语言交互、多因子综合评分、实时市场扫描 |
| AI盯盘 | Activity | 24小时智能盯盘，实时监控异动、突破、量价异常 | 异动实时推送、自定义监控规则、多标的并行监控 |
| 策略生成 | FlaskConical | 描述你的交易逻辑，AI自动生成可执行的量化策略 | 自然语言转策略代码、多策略模板、参数自动优化 |
| 策略回测 | BarChart3 | 一键回测历史数据，可视化收益曲线和风险指标 | 历史数据回测、收益曲线可视化、风险指标分析 |

### 4. 效果展示/案例

- 区域标题：实战效果，数据说话
- 左侧：回测收益曲线示意图（Recharts 绘制静态示意数据）
- 右侧：关键指标卡片
  - 年化收益率
  - 最大回撤
  - 胜率
  - 夏普比率
- 下方：AI选股结果示意（展示几只股票的AI评分和推荐理由）

### 5. FAQ 常见问题

- 区域标题：常见问题
- 手风琴式展开/折叠
- 预设问题与回答：

1. **是否需要编程基础？**
   不需要，全程自然语言交互。你只需用日常语言描述你的交易想法，AI会帮你完成从策略编写到回测执行的全过程。

2. **支持哪些市场？**
   目前支持A股全市场覆盖，包括主板、创业板、科创板和北交所。

3. **AI选股的准确率如何？**
   AI选股是辅助决策工具，结合多种因子模型和技术指标进行综合评分。建议结合自身判断使用，不构成投资建议。

4. **策略回测的数据来源？**
   基于历史真实行情数据，包含日K、分钟K等多周期数据，确保回测结果的可靠性。

5. **是否支持实盘交易？**
   支持模拟交易和实盘对接。建议先在模拟环境验证策略，再进行实盘操作。

### 6. 底部 CTA 区域

- 深色背景
- 标题：开始你的量化交易之旅
- "免费注册" 大按钮 → 跳转 `/login`

### 7. 页脚

- Logo + 版权信息
- 简单链接：关于我们 | 使用条款 | 隐私政策

## 组件结构

```
src/pages/Landing.tsx          — 落地页主组件（单文件，包含所有板块）
```

落地页作为单文件组件实现，内部按板块拆分为局部组件/函数，保持文件可读性。如果后续需要拆分，再提取为独立组件。

## 文件改动清单

1. **新增** `src/pages/Landing.tsx` — 落地页组件
2. **修改** `src/pages/index.ts` — 导出 Landing
3. **修改** `src/App.tsx` — 调整路由结构（`/` → Landing，应用路由移至 `/app`）
4. **修改** `src/components/Layout.tsx` — 更新导航链接路径（添加 `/app` 前缀）
5. **修改** `src/pages/Login.tsx` — 登录成功后跳转 `/app` 而非 `/`

## 设计约束

- 落地页不依赖任何 API 调用，纯静态内容
- 效果展示区域使用硬编码的示意数据
- 不引入新的第三方依赖
- 响应式设计，适配桌面和移动端
- 遵循现有 Tailwind 主题色系（primary 蓝色系）
